# 해외 물류 · 사업 대시보드

주소: https://construction8420-beep.github.io/logistics-dashboard/

## 쓰는 법
- **처음 한 번만:** 오른쪽 위 **깃허브 연결** → 안내대로 토큰을 만들어 붙여 넣기.
  이후로는 적는 즉시 이 저장소의 `data.json`에 자동 저장되고, 팀원 화면에는 1분 안에 반영됩니다.
- 연결하지 않은 브라우저는 **보기 전용**입니다(적으면 그 브라우저에만 남음).
- 팀원이 입력도 하려면: 저장소 Settings → Collaborators에서 초대 → 각자 깃허브 연결.
- 두 사람이 동시에 고쳐도 프로젝트 단위로 자동으로 합쳐집니다(같은 프로젝트를 동시에 고치면 나중 저장이 우선).

## 파일
- `index.html` — 대시보드
- `data.json` — 모든 내용(프로젝트, 브랜드 담당자). 대시보드가 자동으로 고칩니다.
- `index.template.html`, `build.py` — 화면 수정용(`python3 build.py`로 index.html 생성)
